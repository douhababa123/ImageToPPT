Image To Editable PPT

图片转可编辑 PPT 项目说明

本项目提供一个 FastAPI 网页应用：上传一组图片后，系统识别图片中的文字，擦除原图文字区域，并生成带可编辑文本框的 PowerPoint 文件。

一键启动

Windows PowerShell 中进入项目目录，执行：

.\run.ps1

启动后打开 http://127.0.0.1:8000/。

默认限制

  • 单次最多上传 20 张图片。
  • 单张图片最大 25 MB。
  • 支持 PNG、JPG、JPEG、WEBP、BMP。

手动启动

如果需要手动配置环境，可以按下面步骤执行：

python -m venv .venv312
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
.\.venv312\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

关键配置

变量 说明 常用值
OCR_PROVIDER OCR 来源。 local 或 paddle_api
INPAINT_PROVIDER 文字擦除方式。 smart、opencv、lama、none
IMAGE_FIT 图片放入幻灯片时的适配方式。 cover、contain、stretch
MAX_UPLOAD_FILES 单次最多上传图片数量。 默认 20
MAX_UPLOAD_MB 单张图片大小上限。 默认 25

密钥与安全

  • 不要提交、打包或分享本地 .env 文件，它可能包含真实 API key。
  • 对外部署时建议从系统环境变量注入 PADDLE_API_KEY。
  • 上传接口已限制文件数量、大小、扩展名，并会验证文件是否为真实图片。

常见问题

  • 首次使用本地 OCR 或 LaMa 时，模型加载可能较慢，请耐心等待。
  • 如果 LaMa 依赖安装困难，可以在 .env 中设置 INPAINT_PROVIDER=smart 或 opencv。
  • 在线 OCR 需要配置有效的 PADDLE_API_KEY，代理环境可通过 PADDLE_API_USE_ENV_PROXY 控制。
  • 生成失败时，请查看 logs/app.log，前端错误提示会包含任务 ID，便于定位日志。
